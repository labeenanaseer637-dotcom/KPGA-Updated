# KPGJA Website

Responsive website for the Khyber Pakhtunkhwa Gems & Jewellery Association.

## Preview locally

Open `index.html` in Visual Studio Code and use the Live Server extension to preview the site. The pages are plain HTML, CSS, and JavaScript; no build step is required.

## Project contents

- Root HTML files are the public website pages.
- `styles.css` contains shared layout, responsive styles, and animations.
- Root JavaScript files provide navigation, slider, and page interactions.
- `assets/` contains website images and the membership reference form.
- `work/` contains local source-review material and is excluded from Git.

## Registration form

The registration page is currently a front-end prototype. It needs a backend connection before applications can be saved or sent.
